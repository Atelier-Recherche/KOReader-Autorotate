## 📖 Über

KOReader-Plugin (Android), das der Systemausrichtung folgt und den Android-Schalter „Automatische Drehung“ respektiert.

## ⬇️ Installation

1. Diesen Ordner nach `koreader/plugins/autorotate.koplugin/` kopieren (Ordnername muss `autorotate.koplugin` sein).
2. KOReader neu starten.
3. Plugin in der Plugin-Verwaltung aktivieren.

## ✏️ Nutzung

Hauptmenü → **More tools** → **Autorotate par l'Atelier** (Schalter ON/OFF).

Standardmäßig deaktiviert. Eine Gestenaktion `autorotate_toggle` ist ebenfalls verfügbar.

## ⚙️ Verhalten

- **ON**: KOReader folgt der Android-Benutzerausrichtung (`SCREEN_ORIENTATION_USER`).
- **OFF**: die aktuelle Ausrichtung wird gesperrt.
