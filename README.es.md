## 📖 Acerca de

Plugin KOReader (Android) que sigue la orientación del sistema respetando el interruptor « Rotación automática » de Android.

## ⬇️ Instalación

1. Copie esta carpeta a `koreader/plugins/autorotate.koplugin/` (el nombre debe ser `autorotate.koplugin`).
2. Reinicie KOReader.
3. Active el plugin en la gestión de plugins.

## ✏️ Uso

Menú principal → **More tools** → **Autorotate par l'Atelier** (interruptor ON/OFF).

Desactivado por defecto. También hay una acción gestual `autorotate_toggle`.

## ⚙️ Comportamiento

- **ON**: KOReader sigue la orientación de usuario de Android (`SCREEN_ORIENTATION_USER`).
- **OFF**: se bloquea la orientación actual.
