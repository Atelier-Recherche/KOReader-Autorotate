## 📖 About

KOReader plugin (Android) that follows the system orientation while respecting Android’s “Auto-rotate” switch.

## ⬇️ Installation

1. Copy this folder to `koreader/plugins/autorotate.koplugin/` (the folder must be named `autorotate.koplugin`).
2. Restart KOReader.
3. Enable the plugin in Plugin management.

## ✏️ Usage

Main menu → **More tools** → **Autorotate par l'Atelier** (ON/OFF switch).

Disabled by default. A gesture action `autorotate_toggle` is also available.

## ⚙️ Behaviour

- **ON**: KOReader follows Android user orientation (`SCREEN_ORIENTATION_USER`).
- **OFF**: the current orientation is locked.
