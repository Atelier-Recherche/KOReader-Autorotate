## 📖 À propos

Plugin KOReader (Android) pour suivre l'orientation du système, en respectant l'interrupteur « Rotation automatique » d'Android.

## ⬇️ Installation

1. Copier ce dossier vers `koreader/plugins/autorotate.koplugin/` (le dossier doit s'appeler `autorotate.koplugin`).
2. Redémarrer KOReader.
3. Activer le plugin dans le gestionnaire de plugins.

## ✏️ Utilisation

Menu principal → **More tools** → **Autorotate par l'Atelier** (interrupteur ON/OFF).

Désactivé par défaut. Une action gestuelle `autorotate_toggle` est aussi disponible.

## ⚙️ Comportement

- **ON** : KOReader suit l'orientation utilisateur Android (`SCREEN_ORIENTATION_USER`).
- **OFF** : l'orientation courante est verrouillée.
